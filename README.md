# Minox

Лёгкое macOS-приложение в меню-баре для просмотра использования Codex и Claude.

🧭Показывает токены за день и за всё время.

📊Берёт лимиты и lifetime-статистику из аккаунтов, поэтому данные не зависят только от локальных логов.

🔒Токены не сохраняются в проекте: Minox использует системную связку ключей macOS.

## Структура

- `Minox` — исходный код приложения и ресурсы.
- `App` — настройки macOS-приложения.
- `scripts` — вспомогательные скрипты.
- `Design` — исходные версии логотипов.
